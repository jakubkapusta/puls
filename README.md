# Puls

Breakout, w którym każdy klocek jest nutą, a utwór powstaje z tego, jak grasz. Gra przeglądarkowa (telefon w pionie, laptop), Vite + TypeScript, surowy WebGL2, cała muzyka syntezowana w Web Audio.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
npm run sim     # raport balansu z botem
```
